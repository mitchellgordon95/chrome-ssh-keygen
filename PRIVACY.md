# Privacy Policy

**SSH Key Generator** is a Chrome extension that generates SSH keypairs entirely within your browser.

## Data Collection

This extension collects **no data whatsoever**.

- No telemetry or analytics
- No network requests of any kind
- No data leaves your device
- No third-party scripts or services
- No cookies, local storage, or persistent state

## How It Works

All cryptographic operations run locally using the browser's built-in [WebCrypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API). Generated keys exist only in memory until you download them. Once the popup closes, all key material is discarded.

## Permissions

This extension requires **no special permissions**. It does not access your browsing history, tabs, network, or any other browser APIs beyond the standard popup and WebCrypto.
